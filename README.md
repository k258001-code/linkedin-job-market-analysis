# LinkedIn Job Market Analysis using Hadoop & Spark

##  Project Overview

This project analyzes LinkedIn job postings using Big Data technologies such as Hadoop and Apache Spark. The goal is to understand job market trends, salary distributions, in-demand skills, and clustering of job roles using large-scale data processing techniques.

##  Objectives

* Process large-scale job posting data using Hadoop HDFS
* Perform data cleaning and preprocessing using PySpark
* Conduct Exploratory Data Analysis (EDA)
* Analyze salary trends and skill demand
* Apply clustering techniques to group similar jobs
* Visualize insights using Python libraries

##  Technologies Used

* Hadoop HDFS
* Apache Spark (PySpark)
* Python
* Google Colab
* Pandas & NumPy
* Matplotlib & Seaborn

##  Key Features

* Distributed data processing with Hadoop & Spark
* Data preprocessing and feature engineering
* Job market trend analysis
* Salary insights and comparisons
* Skill demand analysis
* Job clustering using machine learning techniques

##  Project Structure

* Jupyter/Colab notebooks
* Python scripts
*  Final report PDF
*  Dataset files (if included)
*  Graphs and visualizations


##  Results

* Identified high-demand skills in the job market
* Observed salary distribution patterns across roles
* Grouped similar job postings using clustering
* Generated visual insights for better understanding of trends
